# OmniVoice React Frontend

Modern React + Vite web user interface for OmniVoice Text-to-Speech synthesis.

## Features

- **Rich Dark Aesthetics**: Glassmorphism design system using pure Vanilla CSS.
- **Dynamic Waveform & Loading Indicators**: Visual feedback during CPU diffusion inference.
- **Voice Controls**: Support for Auto Voice and Voice Design modes with presets and custom attributes.
- **Speed & Diffusion Steps**: Control generation speed (0.5x–1.5x) and inference quality (16 or 32 steps).
- **Direct Playback & Download**: Integrated HTML5 audio player and WAV export.
- **Live Status Probes**: Real-time FastAPI connectivity and model readiness badges.

## Quick Start

```powershell
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build
npm run build
```
